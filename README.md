## ✨ Features

- ⏱️ **Focus Engine (Pomodoro)**: Dynamic circular SVG progress ring with presets (25m Focus, 5m Short Break, 15m Long Break) and session tracking.
- 🎵 **Synthesized Ambient Audio**: 100% native Web Audio API sound generator (Soft Rain, 432Hz Zen Drone, and Ocean Pink Waves). No external audio files or internet required.
- 🎯 **Task Matrix**: Categorized task list (Code, Focus, Design, Life) with filter chips, persistence to `localStorage`, and celebratory confetti animations upon completion.
- 📝 **Auto-Syncing Scratchpad**: Instant notes with word and character count, automatically persisted locally.
- 🎨 **Dynamic Theme System**: Switch between 4 hand-crafted glowing color palettes:
  - **Cyber Violet** (Default Deep Indigo & Violet)
  - **Hyper Neon** (Cyan & Electric Blue)
  - **Sunset Flame** (Vibrant Amber & Solar Red)
  - **Emerald Matrix** (Mint & Jade Glow)
- 💎 **Glassmorphic Aesthetic**: Modern backdrop filters, floating ambient mesh orbs, and responsive design.

No dependencies or installation steps required!

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/marval120/test.git
   cd test
   ```

2. **Open in Browser:**
   Simply double-click `index.html` or open it with your browser of choice:
   ```bash
   # On Windows
   start index.html
   ```

- **HTML5**: Semantic markup & accessibility tags.
